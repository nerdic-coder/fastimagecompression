## Suggested form values

**Startup name**

Fast Image Compression

**Headline (5–8 words)**

Private, browser-based image compression

**Description**

Fast Image Compression is a free browser-based tool for reducing image file sizes without sending the selected images to the application's server. Choose an image, adjust the quality slider, select JPEG, PNG, or WebP output, preview the result, and download it. Processing uses the browser's HTML5 Canvas API, so the workflow is useful for people who want a quick compressor without an account or upload step. The site also includes practical guides for compressing images for email, WordPress, social media, and target file sizes.

The project accepts JPEG, PNG, WebP, GIF, and BMP input and documents a 10 MB maximum file size. Output formats currently documented by the project are JPEG, PNG, and WebP. It is designed for modern browsers and can be tested directly at https://fastimagecompression.com/.
