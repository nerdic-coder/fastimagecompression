### Long description

Fast Image Compression is a free browser-based tool for people who need smaller images without first uploading those image files to an application server. It processes selected JPEG, PNG, and WebP files locally in the browser.

Users can select multiple images, resize them, adjust quality and output format, preview the results, and download the optimized files. Practical workflows include preparing images for websites and WordPress, reducing attachments for email, and working toward common upload-size limits.

The tool requires no registration. Its local-processing approach is especially useful when the contents of an image should remain on the user's device. This claim applies to image-file processing; the website uses site analytics, so the listing should not claim that the entire site performs no tracking or data collection.

### Privacy/local-processing explanation

Selected image files are processed locally in the browser and are not uploaded to the Fast Image Compression application server. This keeps the image-processing workflow on the user's device. The website may still use site analytics, so do not broaden this into a “no tracking” or “no data collection” claim.
