# Fast Image Compression Website

A lightning-fast, modern, responsive web application for compressing images online with a beautiful UI.

**🌐 Live at: [fastimagecompression.com](https://fastimagecompression.com)**

## Features

- **⚡ Ultra-Fast Processing**: Compress images in milliseconds with our optimized engine
- **Drag & Drop Upload**: Easy image upload with drag and drop functionality
- **Quality Control**: Adjustable compression slider (10-100%)
- **Multiple Formats**: Support for JPEG, PNG, and WebP output formats
- **Real-time Preview**: See original and compressed images side by side
- **Compression Stats**: Detailed file size reduction and compression ratio
- **Privacy First**: All processing happens in the browser - no server uploads
- **Mobile Responsive**: Works perfectly on all devices


## How to Use

1. **Upload Image**: Click the upload area or drag and drop an image file
2. **Adjust Quality**: Use the slider to set compression quality (10-100%)
3. **Choose Format**: Select output format (JPEG, PNG, or WebP)
4. **Compress**: Click the "Compress Image" button
5. **Download**: Download your compressed image

## File Support

- **Input Formats**: JPEG, PNG, WebP, GIF, BMP
- **Output Formats**: JPEG, PNG, WebP
- **Max File Size**: 10MB
- **Max Dimensions**: No limit (processed in browser)

## Local Development

### Quick Start (No Server Required)
Simply open `index.html` directly in your browser - the app works offline!

### Local Test Server (Recommended)

For better development experience and testing, use a local server:

#### Option 1: Python (Built-in)
```bash
# Python 3
python -m http.server 8000

# Python 2
python -m SimpleHTTPServer 8000
```
Then visit: `http://localhost:8000`

#### Option 2: Node.js (if you have Node.js installed)
```bash
# Install a simple server globally
npm install -g http-server

# Start server
http-server -p 8000
```
Then visit: `http://localhost:8000`

#### Option 3: PHP (if you have PHP installed)
```bash
php -S localhost:8000
```
Then visit: `http://localhost:8000`

#### Option 4: VS Code Live Server Extension
1. Install "Live Server" extension in VS Code
2. Right-click on `index.html`
3. Select "Open with Live Server"

### Why Use a Local Server?

- **CORS Compliance**: Some browsers block file:// protocol for security
- **Font Loading**: External fonts (Google Fonts) load properly
- **Performance Testing**: More accurate performance measurements
- **Development Tools**: Better debugging and testing capabilities


### Testing Performance Optimizations

After implementing performance optimizations, test with:
1. **Lighthouse**: Use Chrome DevTools Lighthouse tab
2. **Network Throttling**: Test on slow connections
3. **Mobile Testing**: Use Chrome DevTools device emulation
4. **Font Loading**: Verify Font Awesome icons load properly
